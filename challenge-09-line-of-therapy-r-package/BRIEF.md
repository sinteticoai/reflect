# Challenge 9: An R package for line-of-therapy (LOT) calculation

Track: Healthcare (set by Sylvester Comprehensive Cancer Center), area: Precision medicine & drug discovery
Source: https://hackathon.miamiaihub.com/challenges (pulled 2026-10-17)
Box folder: https://miami.box.com/s/2kktjf4ag7zvlhspdngg8a97nyyo27go

Line of therapy (LOT) is a concept widely used by oncologists, regulators and the pharma industry to describe the first and subsequent therapies a patient receives following the first progression event after an initial therapy (radiation, surgery or drug). The hardest part is identifying early-stage patients (I-III) who recur or progress later, as they often receive treatments before the later progression event that would be excluded from the LOT calculation. The LOT definition can vary by disease type and individual data user. Generate a shareable R package that lets data users select their own index date/event and calculate the subsequent LOTs.

Requires completing the AACR GENIE Data Access request: https://miami.box.com/s/vzc7h5rbht8o6623jy58a3qblqnbpitn
