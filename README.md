# health-track

eMerge AI Hackathon 2026 (Oct 17, The Dock), Healthcare track: cancer care challenges set by Sylvester. Source: https://hackathon.miamiaihub.com/challenges (sign-in required). Each challenge folder has BRIEF.md (page text) and data/ (Box folder mirror, pulled 2026-10-17). There is no Challenge 2 on the page.

- 01 survivorship acute care: MEPS survey + Synthea clinical records, baseline model, guide
- 03 wearable rough patch: LifeSnaps, fatigue study, synthetic wearable data
- 04 meals/glucose/movement: CGMacros (CGM + meal photos), NHANES, synthetic data
- 05 coaching conversation scoring: AnnoMI sessions, text coaching, synthetic calls/transcripts
- 06 + 07 compound targets / inhibitor candidates: shared Box folder (07/data symlinks to 06/data). ChEMBL 37 dump, CCLE expression, L1000 annotations, PharmacoDB DSS. NOT downloaded: `Data/DrugSensitivity/L1000 level4 data/level4_beta_trt_cp_n1805898x12328.gctx` (89 GB, larger than free disk). Get it from https://miami.box.com/s/8ru4ny1seo75wrkfsopajzk6kn9rrrcb if needed.
- 08 / 09 / 10 AACR GENIE: shared Box folder (09 and 10 data symlink to 08). Only instructions PDFs; the patient data needs the AACR GENIE Data Access request (https://miami.box.com/s/vzc7h5rbht8o6623jy58a3qblqnbpitn).

Participant Agreement: datasets stay within your team and are used for this hackathon only.
