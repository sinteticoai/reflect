# Challenge 8: An R package that normalises the six AACR GENIE cohorts

Track: Healthcare (set by Sylvester Comprehensive Cancer Center), area: Precision medicine & drug discovery
Source: https://hackathon.miamiaihub.com/challenges (pulled 2026-10-17)
Box folder: https://miami.box.com/s/2kktjf4ag7zvlhspdngg8a97nyyo27go

There are six public clinicogenomic (clinical and genomic) datasets generated by the American Association for Cancer Research (AACR), with minor variances between data variable names and definitions from cohort to cohort. Generate a shareable R package that helps data users normalise the six datasets to allow easier cross-cohort analyses.

Requires completing the AACR GENIE Data Access request: https://miami.box.com/s/vzc7h5rbht8o6623jy58a3qblqnbpitn
